# Community statement on supply point holders (rec-pod-assertion/1)

DRAFT FOR LEGAL REVIEW. This text is a generic draft. It has not been reviewed by legal
counsel and is not agreed with any grid operator. Do not rely on it until it has been.

The energy community (the community) sends this statement each time it asks a data holder,
such as a grid operator, to release a member's data for one or more supply points (POD).
The request names this text by its version and by its fingerprint (sha256).

By sending a request, the community states that:

1. **It checked.** Before the request, the community verified that the member holds each
   supply point named in it. It did so on the evidence named in the request (for example a
   utility bill or an identity document), on the date stated in the request.

2. **It keeps the evidence.** The community keeps the evidence it relied on, or a copy of
   it, for the retention period stated in its agreement with the data holder. That period
   runs from the end of the member's consent. The fingerprints sent in the request let
   anyone check later that the evidence shown is the evidence that was relied on.

3. **It acts when the holder changes.** When the community learns that a member no longer
   holds a supply point (for example after a change of contract holder or a move), it
   withdraws the request for that supply point within the number of days stated in its
   agreement with the data holder.

4. **It is responsible for the statement.** The statement is the community's own. The data
   holder does not check who holds a supply point when it receives the request. If the
   statement turns out to be wrong, the community answers for it, as set out in its
   agreement with the data holder.

The request carries no name, fiscal code or supply point beyond what the release itself
needs. The person who verified is named only by a code that the community alone can
resolve.
